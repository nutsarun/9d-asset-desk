ตั้งค่า Microsoft Entra ID (Azure AD) Single Sign-On

เชื่อมต่อระบบยืนยันตัวตนองค์กรจริงผ่าน MSAL.js 2.0 และกำหนดเงื่อนไขโดเมน

เว้นว่างไว้หากต้องการใช้โหมดจำลอง (Sandbox Mode)

แนะนำให้ใส่ Tenant ID ขององค์กรเพื่อจำกัดเฉพาะผู้ใช้ภายใน

อนุญาตเฉพาะอีเมลที่ลงท้ายด้วยโดเมนนี้ (เว้นว่างเพื่อรับทุกโดเมน)

คัดลอก URL นี้ไปใส่ใน Azure App Registration (SPA)

ขั้นตอนการตั้งค่าใน Microsoft Azure Portal (Entra ID):

  1. เข้าสู่ portal.azure.com > ไปที่เมนู Microsoft Entra ID > App registrations > คลิก New registration
  2. ตั้งชื่อแอป เช่น IT Asset Pro และเลือก Single tenant (Accounts in this organizational directory only)
  3. ในหัวข้อ Redirect URI ให้เลือกแพลตฟอร์มเป็น Single-page application (SPA) และวาง URL ด้านบน
  4. คัดลอกค่า Application (client) ID และ Directory (tenant) ID มาวางในช่องด้านบนแล้วกดบันทึก
ดูตัวอย่างโค้ด MSAL.js Configuration ที่ระบบใช้งาน 
const msalConfig = {
  auth: {
    clientId: "YOUR_CLIENT_ID",
    authority: "https://login.microsoftonline.com/YOUR_TENANT_ID",
    redirectUri: window.location.origin + window.location.pathname
  }
};
const msalInstance = new msal.PublicClientApplication(msalConfig);
const loginResponse = await msalInstance.loginPopup({ scopes: ["User.Read"] });
